# 革命街没有尽头

一部中文互动叙事游戏。故事发生在德黑兰、圣何塞与伊斯坦布尔，以 25 幕固定主线和一间可重访的“记忆剪辑室”讲述女生（莱拉）与男生（阿拉什）失去共同生活的过程。首轮叙述在首次介绍后优先使用“女生、男生、她、他”，只在文书身份或多人场景中保留姓名，降低记忆门槛。当前版本在电影叙事上加入了可探索物件、记忆显影、剧情内对白权益、章末演示礼包与持续卷宗。

## 叙事契约

> 她被处分、离开、结婚与重逢已经发生。你不能改写这些端点，但能决定通往它们的三个动作，以及它们最后如何被记住。

玩家会写下三次主动作——**说出、留住、活下去**——并亲手处理照片、未寄出的邮件与重逢时的视线。宏观端点始终锁定，微观动作、感官细节、未来回响和电影尾声会根据玩家真实做过的事组合；结尾不会替玩家描述没有发生的选择。
第一章新增一次不计分的“心动动作”：玩家可替男生擦掉机油、记住他的到达时间或分享石榴。它不会改变结局，只会改变男生的即时回应、雨夜回声、记忆册与结尾镜头。通关后解锁七日轮换的“今日记忆路线”：每次三步、约 1–2 分钟；同日可以重剪并比较回声，但只在首次完成时推进 1/3/5 日累计残片，避免重复刷取。

## 核心循环

> 探索场景 → 发现线索 → 完成交互 → 提升记忆显影度 → 选择是否查看隐藏对白 → 领取章末演示礼包 → 查看下一章预告。

- 五章共 15 个有叙事用途的互动，每章 3 个；每章都有一项核心玩法、一次有代价的主选择、一个情绪高点和一次章末结算。
- 记忆显影度为 `0–100`，分为五档：基础剧情、内心独白、场景细节与纪念物、隐藏对白预览、完整记忆卷宗与特别尾声。
- 说出 / 留住 / 活下去三条轴继续影响对白、回响和结尾，但不会改写处分、离开、结婚、重逢与再次走散这些端点。
- 照片、电影票、问话记录、处分通知、行李牌、邮件残影与两张同版毕业照会进入持续保存的记忆卷宗。

## 可玩内容

- 25 幕固定主线，包含章节过渡、场景探索、冲突对白与可跳过等待的轻量蒙太奇
- 五章核心玩法依次为：两阶段放映机修复、是否告发同伴、机场点击告别、未发送邮件的写入与点击删除、两张同版毕业照的对齐
- 15 个互动覆盖物件查看、线索排序、组合、点击确认、画面热点和三次主动作选择，不以无意义热点凑数
- 三次主动作都有即时确认、近期后效、跨年代回响与专属结尾片段
- 三种共鸣操作继续保留：放置照片、写入并删除邮件、在重逢画面中移动视线
- 说出 / 留住 / 活下去 / 混合四类总体语气；混合路线不是“更正确”的结局
- 首次通关后解锁“记忆剪辑室”：快速重剪三次主动作，或完整重剪全部六次输入
- 持续记忆卷宗记录显影度、章节增量、下档距离、线索、纪念物、对白状态与 `2/5` 式礼包进度
- 刷新后可续玩；回访章节、次日碎片、下一奖励距离和高显影度特别尾声提供克制的重玩回报
- 自动保存、移动端触控、键盘操作、读屏语义、焦点管理与减少动态支持
- 由用户主动开启的章节环境声与叙事性提示音

## 剧情内对白与演示礼包

五个章节各有一个可选隐藏对白节点。当前只提供**本地模拟权益**：`¥1` 只续接当前隐藏对白的首句，`¥2.9` 解锁本章这一段完整对话，`¥9.9` 解锁五章全部完整对白。三档对应逐级扩大的内容范围，不存在同一内容“低价更全”的价值倒挂；从 `¥1` 升级到 `¥2.9`、或从已解锁章节升级到 `¥9.9` 时，本地演示会抵扣已付金额并合并权益。它不会发起真实付款，也不会产生真实订单；免费主线与完整结局始终可通关。解锁记录只保存在本设备，正式支付、账号和跨端权益服务仍待接入。

每章结算会在剧情物件中显影一个演示码：

- `JD-DEMO-LOVE-01`
- `JD-DEMO-NAMES-02`
- `JD-DEMO-ROAD-03`
- `JD-DEMO-CITIES-04`
- `JD-DEMO-MEMORY-05`

以上均为**无实际面值、不可兑换的界面演示码**，仅用于验证游戏内领取、复制与进度流程；项目未使用京东标识，也不表示与京东存在合作、授权或兑换关系。正式奖励服务待接入。

## 本地运行

Windows 用户可直接双击 [`启动游戏.cmd`](./启动游戏.cmd)。首次运行会自动选择 npm 或 pnpm 安装依赖，随后启动本地服务并打开浏览器。若把 GitHub ZIP 解压在 `Program Files` 等受保护目录且遇到权限错误，请先将整个文件夹移到桌面或“文档”。

也可以使用命令行。需要 Node.js 22.13 或更高版本：

```bash
npm install
npm run dev
```

打开 <http://localhost:3000/>。

若设备已安装 pnpm，也可以运行：

```bash
pnpm install
pnpm exec vinext dev
```

## 项目结构

- `app/page.tsx`：游戏界面、交互状态、存档、首轮与重剪流程
- `app/story.ts`：25 幕剧情、选择契约、未来回响路由与结局文案
- `app/game-logic.ts`：纯结局判定、回响比较与电影尾声组合
- `app/progression.ts`：15 个互动、五章契约、显影度、模拟权益、演示礼包、回访与存档结构
- `app/v6-ui.tsx`：场景探索、隐藏对白、章末结算、持续卷宗与回访界面
- `app/analytics.ts`：22 个本地事件的统一接口与调试日志
- `app/audio-engine.ts`：章节环境声、物件声音母题与生命周期管理
- `app/globals.css`：宽银幕界面、物理交互、响应式与减少动态样式
- `public/`：剧情美术；包含同源毕业照、十三年后人物与桌面/手机安全裁切
- `docs/V6-DESIGN-CONTRACT.md`：当前核心循环、数值、权益、礼包、存档与验收契约
- `tests/`：逻辑、结构、流程与服务端渲染测试

## 核心原则与服务边界

他们最终仍会走散。游戏的参与感不来自改写终点，而来自玩家亲手决定那些通往终点的动作：哪些话说出口，哪些证据留下，哪些句子被删除，以及镜头最后停在哪里。

剧情内价格、礼包码、事件日志与权益均为本地演示实现。当前工程不包含真实支付、真实兑换、正式账号、云端存档或生产分析服务；这些能力必须在合规评审和正式服务接入后才能上线。
