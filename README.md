# 革命街没有尽头

一部约 6–8 分钟的中文互动叙事游戏。故事发生在德黑兰、圣何塞与伊斯坦布尔：玩家无法改变已经发生的历史，只能通过三次选择，决定如何记住莱拉与阿拉什失去的共同生活。

## 当前版本

- 冻结版本：v1.0.0
- 28 个主线场景
- 5 个章节过场、3 组轻量蒙太奇
- 爱情 / 理想 / 生存 / 混合记忆四类结算
- 选择确认、配置化选择回声和仪式化结算
- 回到上一幕、设备本地自动/手动存档
- 首次通关后解锁“重访关键记忆”
- 移动端触控、焦点管理和减少动态支持
- 分章节 Web Audio 环境氛围
- 7 张独立宽银幕剧情美术及社交分享图

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm exec vinext dev
```

打开 http://localhost:3000/。

## 构建与测试

```bash
pnpm exec vinext build
node --test tests/game-logic.test.mjs tests/rendered-html.test.mjs tests/experience-structure.test.mjs
```

当前版本包含 14 项自动化测试，覆盖结局公平性、混合记忆、选择反馈、回退、存档结构、移动端记忆册、快速重玩与声音管理。

## 项目结构

- `app/page.tsx`：游戏界面、状态、存档与交互流程
- `app/story.ts`：主线剧情、选择、回声与结局文案
- `app/game-logic.ts`：可测试的纯结局判定与记忆计算
- `app/audio-engine.ts`：章节化声音管理
- `app/globals.css`：电影化界面与响应式样式
- `public/art-v2/`：当前版本剧情美术
- `tests/`：自动化测试

## 核心设计原则

> 选择不能改变历史，只改变我们如何记住它。

三次选择不会让莱拉与阿拉什复合，也不会抹去他们后来各自的生活。选择只改变记忆的颜色、后续文本回声和玩家最终如何理解这段往事。
