# V3.2 音频与美术资产清单

> 历史资产记录：本文不再定义当前玩家规则。现行叙事、交互和声音入口以 [`V5-DESIGN-CONTRACT.md`](./V5-DESIGN-CONTRACT.md) 为准。

## 音频

游戏使用 Web Audio 实时生成的原创波斯风 BGM，默认关闭，由玩家主动开启。

- 调式：受 Dastgah-e Shur 音程色彩启发，包含介于十二平均律琴键之间的二度与六度。
- 音色：setar 式短促弹拨、santur 式双击泛音、tombak 式低频手鼓。
- 编曲：七个章节分别使用不同速度、音区、旋律密度和鼓点；旋律保持稀疏，避免干扰阅读。
- 版权：程序化原创旋律，不引用现成歌曲。
